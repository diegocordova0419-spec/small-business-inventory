# Small Business Inventory Management System

Initial frontend project setup using React, Vite, JavaScript, Tailwind CSS, React Router, and Lucide React.

## Development

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Source structure

- `src/components/` holds reusable UI, dashboard, and inventory components.
- `src/pages/` holds the application page placeholders.
- `src/layouts/` holds shared page layouts.
- `src/hooks/`, `src/context/`, `src/lib/`, `src/services/`, and `src/utils/` are reserved for future shared code.
- `src/assets/` holds static assets.

The current routes are `/login`, `/dashboard`, `/inventory`, `/products`, `/orders`, `/suppliers`, `/customers`, and `/reports`. Pages are placeholders at this setup stage.
